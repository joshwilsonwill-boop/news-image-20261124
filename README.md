# Sum up 24 November's world news in one image

One image summing up the world's news of Tuesday 24 November 2026: Kyiv region strikes, drones over Khartoum, the first state suits over Grok deepfakes, Nvidia bringing back its chief executive, the Japan trade deal, and Bangladesh's typhoid drive. Drawn procedurally with PIL in draw.py, no photographs, no network.
